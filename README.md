# Titanic Survival Prediction — Logistic Regression

## Overview
This project applies Logistic Regression, a classification algorithm, to predict passenger survival using the Titanic dataset.

The goal of this project was to practice the Machine Learning workflow, from exploring and preprocessing data to training a model and evaluating its performance.

## Project Workflow

- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib and Seaborn
- Feature selection
- Handling missing values
- Outlier detection using the IQR method
- Train-test split
- Encoding categorical features using OrdinalEncoder
- Training a Logistic Regression model
- Evaluating the model using Accuracy Score

## Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

Titanic dataset — used to predict whether passengers survived the Titanic disaster.

## Model

Logistic Regression

## Evaluation

The model was evaluated using Accuracy Score on the test dataset.
